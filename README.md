# Ringsure site

Support page and privacy policy for the Ringsure: Ring Sizer iOS app, served with GitHub Pages at
https://sleepsheeps.github.io/ringsure-site/

App Store Connect has them as the support URL and the privacy policy URL. `privacy.html` must
resolve, or App Store review stops on it.

The privacy policy describes what the app actually does: no data collected, no permissions, no
network. If the app ever starts using the network, a permission or a third-party SDK, update
`privacy.html` (and the App Store privacy label) in the same change.
